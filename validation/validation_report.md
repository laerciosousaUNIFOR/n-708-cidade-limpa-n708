# Relatório de Validação

## Objetivo

Validar a solução Cidade Limpa junto ao público-alvo identificado durante a etapa anterior do projeto.

## Participante

Nome: Matheus Araujo

Função: Morador da Região

Localização: Eusébio - CE

## Processo de Validação

O sistema foi apresentado ao participante para demonstração das funcionalidades implementadas.

Foram demonstradas as seguintes funcionalidades:

- Cadastro de ocorrências urbanas
- Listagem das ocorrências registradas
- Atualização do status das ocorrências
- Interface web para interação do usuário

## Feedback Recebido

O participante considerou a proposta útil para facilitar o registro de problemas urbanos enfrentados pela comunidade.

Foi destacado que a possibilidade de acompanhar o status das ocorrências pode incentivar maior participação dos moradores e melhorar a comunicação entre cidadãos e responsáveis pela manutenção urbana.

## Conclusão

A validação indicou que a solução atende ao objetivo principal do projeto, oferecendo uma forma simples e acessível para registrar e acompanhar problemas urbanos.

O feedback obtido reforçou a relevância da proposta e sua aderência ao público-alvo definido.
